# JRA ダート予想アプリ：スマホから直接取得（2026-11-05版）

## 使い方

1. `app.py` を現在のStreamlitアプリのPythonファイルと差し替える。
2. `requirements.txt` を同じリポジトリのルートに配置する（すでにある場合は必要なライブラリを統合する）。
3. アプリを再起動またはStreamlit Cloudで再デプロイする。
4. スマートフォンでアプリを開き、「📱 スマホで出走表・過去成績・3連複人気を取得」の開催日を指定する。
5. 「📲 出走表＋過去成績＋3連複人気を一括取得」を押す。
6. 出走表・過去成績・3連複オッズ人気・失敗診断をZIPで保存できる。

## 取得するもの

- 開催日6〜12RのJRAダートレースの出走表（馬番・馬名・馬ID・オッズ・人気）
- 出走各馬の過去成績（芝・ダート全件、**当日および未来を除外**）
- 全組合せの3連複オッズと組合せ別人気順位（取得日時・時点区分付き）
- レースごとのエラーと馬ごとの履歴取得失敗の診断
- 旧AI・新AIの既存予想画面への反映

## 変更しないもの

- 旧AI・新AIの能力評価式、3連複4頭BOX表示、保存済み予想・長期成績表示
- Ver15の検証画面は復活させない。
- 既存Google Drive Excel読込・3連複人気だけの更新ボタンも残す。

## 注意

- スマートフォンにPythonは不要です。処理はStreamlitアプリが動くサーバー上で行われます。
- スマホから直接取得した内容はそのStreamlitセッションに保持。サーバー再起動時に失われるため、ZIP保存してください。
- GitHubトークンを設定している場合は従来どおり3連複市場データのスナップショットを保存します。出走表・過去成績の自動GitHub保存は実装していません。
- 既存Excelと採点条件を合わせるため、**指数に使用する過去走は直近4走**です。取得した全履歴はZIPに保存します。
- 公式の発走時刻が読み取れない時や発走後のデータを、発走前予想として保存できません。
- 3連複オッズや人気を推測で埋めず、組合せ数不一致もエラーとして記録します。
- netkeibaの通信制限・ページ構造変更がある場合は取得に失敗します。HTTP取得・HTML解析を実サイトでテストしたものではないため、最初の実行で「スマホ直接取得の成功・失敗診断」を確認してください。
- 出走前に取得した市場スナップショットのみ、将来の購入判定モデルの入力候補として利用してください。
